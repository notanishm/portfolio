# Portfolio - Anish Maisekar

Single-page portfolio built with React + Vite + Tailwind.

## Run Locally

```bash
cd anish-portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Update Content

Edit: `src/data/content.js`

## Profile Photo

Place your photo here:

`public/profile-photo.jpg`
